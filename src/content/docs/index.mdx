## 🔐 Authentication APIs

This documentation covers complete authentication flows including:

- **AWS Cognito OAuth2**: Client credentials flow for server-to-server authentication
- **User Authentication**: Email/password login and registration
- **Token Management**: JWT token handling and refresh
- **Multi-Environment**: Development, staging, and production configurations

## 🌍 Environment Support

### Development
```bash
npm run dev
# Uses: .env.local or config.js defaults
```

### Staging  
```bash
npm run dev:staging
# Uses: .env.staging.local or staging config
```

### Production
```bash
npm run dev:prod
# Uses: environment variables from hosting platform
```
